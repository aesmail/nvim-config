# Snippet sources and changes

The JSON files in this directory are generated by `scripts/tmbundle2snippets.py` from TextMate
bundles. They are converted from TextMate's `.tmSnippet` plists to VS Code-format JSON, and some
snippets were changed in the process. Each snippet's `description` names the bundle it came from;
snippets that were written for this config are labelled `Added (...)`.

## Elixir — `elixir.json`, `eelixir.json`, `heex.json`

Source: [elixir-editors/elixir-tmbundle](https://github.com/elixir-editors/elixir-tmbundle),
Copyright 2012 Plataformatec, licensed under the Apache License, Version 2.0
(see `LICENSE-elixir-tmbundle`).

These files are modified versions of the bundle's snippets:

- converted from TextMate plist snippets to VS Code JSON; TextMate regex transformations were
  rewritten as JavaScript-regex transformations (`fn`)
- `defmodule` (`defmod`) derives the module name from the file path
  (`lib/my_app/accounts/user.ex` -> `MyApp.Accounts.User`) instead of the file name
- `defcallback` (`defc`) and `defmacrocallback` (`defmc`) now insert `@callback` /
  `@macrocallback`, which replaced those macros in Elixir
- the scope-less "Embedded Code" snippet (no tab trigger) is omitted
- added, not from the bundle: `mount`, `he`, `hi`, `render` (Phoenix LiveView)

## Ruby on Rails — `rails*.json`, `eruby.json`

Source: [textmate/ruby-on-rails-tmbundle](https://github.com/textmate/ruby-on-rails-tmbundle),
Copyright (c) 2006 syncPEOPLE, LLC, MIT License (see `LICENSE-ruby-on-rails-tmbundle`).

Changes: converted to VS Code JSON; snippets for APIs removed from Rails (RJS, `render :text`,
`find(:all)`, `map.resources`, ...) are dropped; the rest are modernised (`before_action`,
`key:` hash syntax, `<%=` for block helpers, Turbo's `turbo_submits_with`). Added, not from the
bundle: `ba`, `pe`, `fw`.

## Ruby — `ruby.json`

Source: [textmate/ruby.tmbundle](https://github.com/textmate/ruby.tmbundle): "Permission to
copy, use, modify, sell and distribute this software is granted. This software is provided "as is"
without express or implied warranty, and with no claim as to its suitability for any purpose."

Changes: converted to VS Code JSON; shell interpolation replaced with its default output;
TextMate regex transformations rewritten as JavaScript-regex transformations; literal
`:key => value` pairs written as `key: value`.
